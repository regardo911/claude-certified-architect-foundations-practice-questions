# Claude Certified Architect Foundations: Practice Questions Score Sheets

**By Chapter 12 you've scored every mock on paper and written GO or WAIT yourself.**

The companion to the book *Claude Certified Architect Foundations: 500+ Practice Questions*, from [youcanbuildthings.com](https://youcanbuildthings.com).

![The 11 score sheets in the order you fill them, grouped Start (Chapters 2-3), Drill (4-8), Mock (9-11 and Appendix A) and Decide (12), beside the book's Chapter 12 example verdict: Agentic 84%, Claude Code 88%, Prompt 80%, Tool/MCP 72% and Context 69% against the 75% line, ending "WAIT. Drill Context first."](docs/images/hero.png)

The questions and keys are in the book. These are the pages you mark them on, already ruled. Two terms from Chapter 2: the *scorecard* has one row per domain, and you fill it after the diagnostic and every drill. The *drill bar* is 75%, the score you want on a set before moving on. It's not the exam's 720 pass mark, and Chapter 2 explains why the two don't convert. Pick your starting point below.

## Start here

### I'm about to start the book

Print the [scorecard and miss-log](chapters/02-scorecard/scorecard-and-miss-log.md) and the [diagnostic answer sheet](chapters/03-diagnostic/answer-sheet.md). The diagnostic is Chapter 3, forty questions, about eighty minutes.

### I'm about to sit a mock

Print a [mock answer sheet](chapters/09-11-mocks/answer-sheet.md) for the sitting, and keep [score by domain](chapters/09-11-mocks/score-by-domain.md) face down until you've marked it.

### I've just finished Mock 3

Fill in the [readiness verdict](chapters/12-verdict/readiness-verdict.md).

Every sheet has a PDF beside it with the same name; open it and print. To edit one on screen, open the `.md` and use **Copy raw file**. For all of them at once, use **Code**, then **Download ZIP**.

If you print only one thing today, make it the scorecard. Every chapter after Chapter 2 writes into it.
