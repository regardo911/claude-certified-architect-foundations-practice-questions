# Chapter 2: the scorecard

Chapter 2 calls this "the instrument you'll fill for the rest of the book." Print [scorecard-and-miss-log.pdf](scorecard-and-miss-log.pdf) before you answer a single question.

Page 1 is the scorecard: one row per domain, with the weight and the 75% target already in. You'll write a Score% into a row after the diagnostic and again after each drill, so pencil helps. Page 2 is the miss-log. You'll fill it fast, so print three or four copies of that page and keep them together.

The trap column wants a number from 1 to 7. The seven names are printed above the log so you don't have to flip back to Chapter 2 mid-mark.

You're done with this chapter when you have what its CHECKPOINT asks for: "a blank scorecard and an empty miss-log before you drill a single question." The first numbers go in at the end of [Chapter 3](../03-diagnostic/).
