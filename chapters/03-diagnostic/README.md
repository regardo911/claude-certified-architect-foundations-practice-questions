# Chapter 3: the diagnostic

Forty questions across all five domains, about eighty minutes. Two sheets, one copy of each.

## While you sit it

Write your letters on [answer-sheet.pdf](answer-sheet.pdf). The sheet groups the forty by domain, the same way the chapter's headings do, so you can count each domain the moment you've marked it.

## When all forty have a letter

Mark them against the chapter's explanations. Count the right answers in each group and copy them into [readiness-map.pdf](readiness-map.pdf). Work out each Score%, then the gap below 75%, then rank the gaps. Rank 1 is your biggest gap, and that's the domain you drill first. The same Score% goes into your [scorecard](../02-scorecard/scorecard-and-miss-log.md), and every miss goes into the miss-log.

The chapter's CHECKPOINT: "every domain has a percentage and a gap number, and you know which domain is furthest below 75%."

Chapter 3 gives two other rules for what to drill first. The map uses the one in the BUILD STEP. [BOOK-FIXES.md](../../BOOK-FIXES.md) has all three.
