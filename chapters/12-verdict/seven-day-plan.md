# 7-day finishing plan

For a WAIT, or a GO with a thin margin. Relative days, so it fits whenever you start.

| My weakest domain | |
|---|---|
| My second-weakest domain | |

| Day | What you do | Done |
|---|---|---|
| Day 1 | Re-drill your weakest domain: the whole chapter, plus its miss-log. Cover the options and re-decide every missed item. | |
| Day 2 | Re-drill your second-weakest domain the same way. Update your scorecard. | |
| Day 3 | Re-take only the questions you missed across all three mocks. Run your trap checklist against each one. | |
| Day 4 | Mock 4 from Appendix A: timed, 120 minutes, closed-book. Score it, tag the misses. | |
| Day 5 | Review Mock 4's misses. Re-drill any domain still under 75%. Add new traps to your checklist. | |
| Day 6 | Dress rehearsal, same time of day as the real exam. The official practice exam in the partner portal if you have access; if not, Mock 5, timed. | |
| Day 7 | No new material. Read your trap checklist and your exam-day card. Rest. | |

Then re-run your [verdict](readiness-verdict.md). If it's GO now, book it.
